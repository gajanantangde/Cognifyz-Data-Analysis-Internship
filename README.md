# Cognifyz Data Analysis Internship

## 📊 Project Overview

This repository contains my **Data Analysis Internship project at Cognifyz Technologies**.

The project focuses on analyzing restaurant data using Python and data analysis and visualization libraries. The analysis covers restaurant cuisines, locations, ratings, votes, price ranges, online delivery, table booking, restaurant chains, and other business-related patterns.

The internship task set is divided into **Level 1, Level 2, and Level 3**, with multiple analytical tasks in each level.

---

## 🎯 Objectives

The main objectives of this project are to:

* Perform exploratory data analysis on restaurant data.
* Identify meaningful patterns and trends.
* Analyze restaurant ratings and customer engagement.
* Study relationships between price range and restaurant services.
* Analyze restaurant locations and geographic distribution.
* Create clear and informative visualizations.
* Generate business-oriented insights from the dataset.

# 📌 Internship Tasks

## Level 1

### Task 1 — Top Cuisines

* Determine the three most common cuisines.
* Calculate the percentage of restaurants serving each cuisine.

### Task 2 — City Analysis

* Identify the city with the highest number of restaurants.
* Calculate the average rating for restaurants in each city.
* Determine the city with the highest average rating.

### Task 3 — Price Range Distribution

* Visualize the distribution of restaurant price ranges.
* Calculate the percentage of restaurants in each price range category.

### Task 4 — Online Delivery

* Calculate the percentage of restaurants offering online delivery.
* Compare the average ratings of restaurants with and without online delivery.

---

## Level 2

### Task 1 — Restaurant Ratings

* Analyze the distribution of aggregate ratings.
* Determine the most common rating range.
* Calculate the average number of votes received by restaurants.

### Task 2 — Cuisine Combination

* Identify the most common cuisine combinations.
* Analyze whether particular cuisine combinations tend to have higher ratings.

### Task 3 — Geographic Analysis

* Plot restaurant locations using latitude and longitude.
* Identify geographic patterns and restaurant clusters.

### Task 4 — Restaurant Chains

* Identify restaurant chains present in the dataset.
* Analyze the ratings and popularity of different restaurant chains.

---

## Level 3

### Task 1 — Restaurant Reviews

* Analyze available restaurant rating information.
* Classify rating categories into positive, neutral, and negative groups.
* Analyze the distribution of rating sentiment.

**Dataset limitation:** The provided dataset does not contain customer-written review text. Therefore, actual positive/negative review keywords and review-length analysis cannot be calculated reliably from the available data.

### Task 2 — Votes Analysis

* Identify restaurants with the highest and lowest number of votes.
* Analyze the correlation between votes and restaurant ratings.
* Visualize the relationship between votes and aggregate ratings.

### Task 3 — Price Range vs. Online Delivery and Table Booking

* Analyze the relationship between price range and online delivery.
* Analyze the relationship between price range and table booking.
* Determine whether higher-priced restaurants are more likely to offer these services.
